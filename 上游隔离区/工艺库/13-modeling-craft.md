# 13 建模工艺（三级分层：从 blockout 到精细模型）

> 定位：**工艺层**手册——"按什么顺序建、每个阶段怎么验收、什么时候停手"。
> 与 12 分册 §2 正交：M4 四阶段是**产出维度**隔离（几何/材质/构图/灯光），本册是**几何阶段内部**的工艺顺序。
> 分层规则（按利弊调研裁定，来源 docs/research-craft-constraints-20260913.md；v2.1 与 §1 表对齐，F-61）：
> **Tier 1 硬性不变量**（幂等/预算/安全/命名 + 阶段出口状态不变量 + **各阶段出口判据**，不许偏离，见 §1）｜
> **Tier 2 默认打法**（**§2 阶段顺序与做法、§3 阶段卡**，允许声明式偏离）｜
> **Tier 3 条件表**（**§4~§5**，只描述不强制）。
> 素材来源：五流派教程对照 + Polycount/topoguide 公理 + 坦克/爱弥丝/DSH 实战（详见各条标注）。

## §1 三级分层总则

| 层 | 内容 | 偏离规则 |
|---|---|---|
| **Tier 1 不变量** | 幂等/预算/安全/命名（=铁律与 12 §1）+ **阶段出口状态不变量**（每阶段结束场景必须合法、可渲染、可保存）+ **各阶段出口判据**（§2 表末列，G 门判据——v2.1 起：判据标准不可降格，经 §6⑥ 用户明示可省略门但 R4 留痕；G1 铁门禁不可省略） | 判据不许降格 |
| **Tier 2 默认打法** | 本册 §2 七阶段卡的**阶段顺序与做法** + §6 偏离机制 | 声明式偏离：report 里加 `deviation: <命中触发条件>` 一句，自评即过 |
| **Tier 3 条件表** | §4~§5 规则与流派差异 | 不需要理由，按适用条件取用 |

**DETAIL_LEVEL 参数**（骨架①参数区可设，默认 standard；F-55 修正：它只决定**细节深度上限**，
阶段 5 拓扑清理与阶段 6 UV/交付**恒走**——任何交付物都需要干净拓扑与导出，不属于"深度"）：
`draft`=细节止于阶段 2（blockout+比例，面数 ≤2k）；`standard`=细节到阶段 4（含细节，≤50k）；
`fine`=全阶段细节+加密（预算按 07 分册平台表）。深度决定细节停手位置，不是质量承诺——
质量承诺由交互档的执行契约承担（00 分册 §1：过程门 G 配置 + 出品门 R1~R6）。

## §2 七阶段管线（默认打法；五流派共识阶段）

| 阶段 | 一句话 | 出口判据（判据标准 Tier 1 不可降格，可机验；门可经 §6⑥ 用户明示降档省略，R4 留痕） |
|---|---|---|
| 0 参考锚定 | 参考板 + 真实尺度 | 三视图/参考图就位**且模型已实看**（U-03 同族：对话内图已可见；**文件路径形态的参考图必须用文件读取工具打开实看**——没看过参考图，后续一切"对照参考"均为空谈；**实看后把视觉规格摘录进 report 与卡片**——提取清单见 14 分册 §2 开场识别）；视觉通道不可达时记 `deviation: 参考图未实看(<原因>)` 并按 00 分册 R1 降级条款处理（F-93：G0 出口专属通道，交付门 △ 无处记录此项）；尺度锚（真实米制）写入 report |
| 1 Blockout | 大形体量，**禁细节** | 剪影渲染 1 张，主体可辨认 |
| 2 Primary 修正 | 对照参考修比例 | 剪影对比图（前/侧）+ 比例核对（proportion report） |
| 3 Secondary 结构 | 部件位置关系与层次 | 部件清单 diff（数量/命名）+ 中距离快渲 |
| 4 Tertiary 细节 | 倒角/纹路/小件 | 细节清单勾选 + 特写快渲 |
| 5 拓扑清理 | 退化/重复/法线 | 体检 report 全绿（07 分册 §1） |
| 6 UV/交付 | UV/烘焙/导出 | 07 分册 §8 清单 + 导出回读 |

**铁门禁**：阶段 1 剪影未过关，**禁止进入阶段 3 之后的任何细节工作**（返工模式 TOP1 的预防）。

**质量门编号**【v1.10.6，供 00 分册执行契约引用；v2.0 自审修订；v2.1 语义修正】：阶段 0→
**G0** 参考锚定（由 R2 的 report 字段承载——尺度锚入 report，不设独立门）／ 阶段 2→**G1**
剪影比例门 ／ 阶段 4→**G2** 结构细节门 ／ 阶段 5→**G3** 体检门 ／ 阶段 6→**G4** 交付门。
**门的两层语义**：判据标准 = Tier 1 不可降格（上表"出口判据"列；凡执行的门逐项真实通过，
产出物可从简——低分辨率快渲亦可——但结论必须真实）；门的存在与位置 = 由 00 分册档位配置
决定，用户明示降档（§6⑥）可省略门（R4 留痕）；**G1 铁门禁不可省略**（大形未过关禁细节；
唯一合法出口是 draft 本就不做细节）。各档门配置见 00 分册 §1「执行契约与质量门」。

## §3 阶段卡

### 卡 1 Blockout（大形）
- **目标**：体量与比例，用最少的 primitive 摆出剪影。此阶段修改器越少越好。
- **做法**：按参考图把主体拆成 3~7 个大块（box/cylinder），只调位置与整体尺寸；
  复杂轮廓用「2D 剖面 + 挤出」时，**转角圆角在剖面生成参数层做**（BMCP-经验 M-07：
  挤出会让剖面每个转角变成长棱，实例=180 条 >0.8m 长棱贯通车体）。
- **出口**：剪影渲染 → 对照参考剪影 → 可辨认即过。
- **返工**：主体剪影不像 → 回本卡，**不许带病进阶段 3**（推倒重来通道，BMCP-ERR-006 同源）。

### 卡 2 Primary（比例修正）
- **目标**：把 blockout 的比例修正到与参考一致。
- **做法**：三视图对照（前/侧）；比例核对脚本（report 里逐件列出 期望/实际 尺寸）；
  相机若参与构图验收，按 FOV 反算距离：`d = span/2 × f/(sensor/2 × 帧占比)`（经验 M-03：倍率凑距离会整车出画）。
- **返工**：比例不合格 → 回卡 1 重做 blockout（推倒重来通道）。

### 卡 3 Secondary（结构）
- **目标**：部件切分与位置关系（面板线、开孔、组件边界）——**仍然不是细节**。
- **做法**：Boolean 切割按 §4 规范；部件间留结构缝隙（真实物体没有绝对贴合）；
  贴花/装饰面片的定位**先量主体外表面实测值**（经验 M-05：面片埋进装甲 = 主体标称尺寸骗人）。
- **量外表面的手段（F-26 整改）**：`obj.ray_cast(origin, direction)` 取命中点
  `loc + normal×offset` 定位——纯 ray_cast 安全模式友好，实测 20+ 件命中率 100%；
  **命中失败即跳过该件**（容错写法），勿硬塞。

### 卡 4 Tertiary（细节）
- **目标**：倒角、纹路、小件——服务剪影可信度，不是堆量。
- **倒角宽度按渲染像素反推**（BMCP-经验 M-08）：`1px ≈ 场景跨度 / 水平分辨率`，
  10m 车渲 1920px 时 1px≈5.3mm——2.6mm 倒角不足半像素=白做，6.5cm≈12px 才可见。
- **细节梯度**：特写件密、中景疏、远景用剪影/贴图顶（§5 距离判据）。
- **收尾顺序**：Boolean → 支撑边/倒角 → Weighted Normal **最后**（栈顺序见 §4）。

### 卡 5 拓扑清理
- 体检全绿（07 分册 §1）：非流形 0 / 零面积 0 / 法线一致；
- **退化清理跟在每次程序化几何操作后**（BMCP-实战 S-09：clamp_overlap 倒角会产生海量
  退化面——实测占单网格 67%、被 Bevel 放大 8 倍；**放阶段 5 就晚了**，阶段 4 之后全部
  产物都建立在脏几何上）→
  `bmesh.ops.dissolve_degenerate(dist=…) + remove_doubles(dist=…)` 操作后立即做，
  **阶段 5 只做终检**。收益是双向的：清理不仅修脏几何，**总面数还反降 22%**
  （实测 102,414 → 78,750——退化面本身就在虚增面数）；
- 角度类审计**必须加面积/边长过滤**（S-11：小段圆柱相邻面天然 60° 会被误报成锐边，
  加 `面积>0.012m² 且边长>0.22m` 过滤后 53,216 条假锐边只剩 6 处真问题）。

### 卡 6 UV/交付
- UV/烘焙/导出全流程见 07 分册 §6~§8 与 06 分册；本卡只提醒交付三件：
  净化（删辅助物/高模）、引擎设置（引擎/色调映射/灯自含）、机验清单（P-03）。

## §4 硬表面专线（AI 主场；规则来源【文献】+实战标注）

1. **大形冻结门禁**：一切切割前，比例/轮廓定稿。【共识】
2. **Cutter 规范**：独立 collection 统一管理；用简单封闭体（非薄片）；切割体**穿出目标表面**（防共面残面）。【摘要】
3. **栈顺序**：Boolean 在前，Bevel/Weighted Normal 在后（Blender Manual「顺序改变结果」推论）。【原文】
4. **Weighted Normal 放栈尾**，配 smooth-by-angle。【原文：Blender Manual】
5. **bevel-after-boolean 两路线**：要 Subsurf 的件走手动 cleanup+实体倒角；纯 spec/游戏件走 Bevel modifier 对 sharp 统一倒角。【摘要/共识】
6. **支撑边距离=硬度**：holding edge 离主边越近，细分后越硬。【摘要】
7. **何时 apply Boolean**：栈过长影响性能 / 要手动修拓扑 / 进 bake-final 才 apply；平时保持 live。【共识】
8. **n-gon 适用条件**：平面且不经 Subsurf 的区域可容；细分/变形区必须 quad+支撑边
   （weighted-normal 路线可容 n-gon，subsurf 路线不容——两派核心分歧，按交付目标选）。【摘要】
9. **剖面转角圆角分区给半径**（BMCP-经验 M-07）：参考图定哪些是真大圆角（实例：整车只 4 处），
   其余保持锐边；半径分区（关键区 6.5cm / 通用 3cm / 小件 1cm）。

## §5 有机专线（AI 勉强区，如实标注）

1. **边环密度随变形走**：面片对齐旋转轴；poles/n-gon 搬到低变形区；密度只加在运动区。【文献·topoguide】
2. **收环 flow**：2-1 / 3-1 / 4-1 / 4-2 / 5-3 标准减环法，减少 distortion。【文献】
3. **pole 处理**：细分下 pinching——**搬移而非消除**，放平缓区。【文献】
4. **A-class 表面**：环距均匀 → 避免高密度 pole 聚集 → 平滑后再加曲率冲突 → 优先 edge crease 省线。【文献】
5. **倒角宽度过渡三法**：edge crease / smooth bevel+holding edge / sharp chamfer。【文献】
6. **转 sculpt 侧门判据**：细节是表面起伏（凹痕/松弛）且 subsurf 跟进成本过高时
   （donut icing 即此逻辑）；硬边界（边缘/孔）回编辑模式。流程：blockout → sculpt(二级形) → retopo。
7. **手足**：先 mark primary loops，难过渡处先解决 loop 转向再 inset；踝部收环目标 16/24 环。【文献】

## §6 偏离与推倒重来机制（Tier 2 运行规则）

- **合法偏离触发条件**（命中即在 report 写 `deviation: <条件>`，自评即过）：
  ① 有机资产 → sculpt-first；② kitbash/素材库可满足 → assembly-first；
  ③ 纯参数化产品 → constraint-first；④ 用户给了网格参考/明确模型 → 跳过 blockout 直接建；
  ⑤ DETAIL_LEVEL=draft → 细节止于阶段 2（阶段 5 清理/阶段 6 交付恒走，见 §1）；
  ⑥ 用户明示赶时间/嫌流程重 → **降档执行**（档间规则全状态表见 00 分册降档通道：升级
   跨档直达、降档逐级——无限挡→完整档→快速档，快速档为管线最低档、管线任务不得降至直通档
   〔任务类型中立表述，F-64〕；DETAIL_LEVEL 降档不自动下调、**升级不得低于目标档下限**
   〔F-66 同步，权威定义见 00 分册第四维〕；
   被省略的门逐条 `deviation:` 留痕——
   G1 铁门禁不可省略；出品底线 R1~R4 仍须逐项报出——✓ 附证据 / N/A 附理由 /
   视觉不可达标 △(原因)（三态穷尽，见 00 分册 R1 降级条款），永不静默省略）。
- **推倒重来通道**：blockout/primary 评审不合格 → 回卡 1/卡 2 重做；
  **禁止**在坏骨架上继续阶段 4 细节（error propagation 防线，SEIG 已证早期错误会向下游传播）。
- **阶段出口检查只在边界做**：渲染+report 评审，阶段内部不逐步设卡（航空清单教训：
  清单在清晰停顿点才有增益，连续创作流中逐条执行变成负担）。

## §7 精细度停手判据（何时停手）

1. **剪影测试**：纯黑轮廓渲染仍可辨认 = 大形合格（风格化/环境线共同验收动作）；
   **视觉核验（U-03）**：一切"可辨认/构图正确/贴图正常"的判断，必须以**像素实际进入
   模型视觉上下文**为前提——渲染/截图落盘后用文件读取工具（名称随客户端）打开 PNG 实看，
   或固化视角后 `get_viewport_screenshot`；**落盘回读只证明文件存在，禁止凭 report
   数字想象画面**（预设多模态模型不看图同样等于瞎）。**感知前提与降级（F-77a 补出口）**：
   视觉通道不可达（路由无图像输入/读图被拒）时按 00 分册 R1 降级条款处理——标
   `R1△(视觉未核验:<原因>)` 并注明，不得假称合格；确认链路故障才走 SKILL.md §6 排障。
   **视觉义务点穷举清单（F-93 收口；v2.2.10 补第 7 处，F-96；v2.3.1 扩容覆盖 14 分册新增义务，F-114；v2.4.0 补 ⑭⑮ 至 15 项，F-127）**：
   ①00 R1 最终渲染 ②00 E 型动画帧抽查 ③12 眼快扫 ④12 快渲 ⑤13 §7 本条 ⑥13 卡 0 参考图实看
   ⑦SKILL §4 视觉核验 ⑧14 §2 场景视觉盘点 ⑨14 §2 参考规格提取 ⑩14 §3 过程实时闭环
   ⑪14 §4 成品展示 ⑫14 §5 资产检索实看 ⑬fragments 组件预览 ⑭14 §1 感知前提自检（固化截图实看）
   ⑮14 §5.3 worked example 视觉引用——新增任何实看义务必须同步
   △ 出口，不得只立义务不给出路；
2. **像素判据**：细节在目标分辨率下 ≥2px 才值得做（M-08 反推公式）；
3. **距离分级**：特写件 full detail / 中景结构 / 远景剪影+贴图；
4. **面数预算**：按 07 分册平台表；预算用**乘法之后的实测值**（倒角/细分后再量，
   实测教训：9.8k 基面经倒角+细分变 8150 万面）；
5. **时间盒**：单资产细节投入以上限封顶（行业 art test 惯例：限时双资产）。
