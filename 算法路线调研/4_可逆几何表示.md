## 1. 里程碑成果

1. **OpenSCAD**（Kintel 等，2009–）：脚本 → AST → CSG 树 → CGAL/Manifold 求值。模型即文本，撤销 = 改文本重编译；视图里的每个元素都能反查到 CSG 节点。证明"全参数化表示下撤销退化为文本 diff，信息零损失"。
2. **Antimony**（Matt Keeter / Formlabs，2014–，mattkeeter.com/projects/antimony）：DAG 节点图 + F-Rep（距离场）几何内核。几何以"指令序列"存储，改动自动向下游传播，STL 导出分辨率与建模过程解耦。证明 DAG + 隐式场可组成完整 CAD。
3. **OpenVDB**（Ken Museth / DreamWorks，SIGGRAPH ToG 2013，"VDB: High-Resolution Sparse Volumes with Dynamic Topology"）：窄带 level set（表面两侧各约 3 体素活动带）+ B 树式稀疏结构，近 O(1) 随机访问，动态拓扑。布尔 = CSG 工具直接在窄带上做 min/max。工业界隐式体积的事实标准（Houdini/MoonRay 均内置）。
4. **DeepSDF**（Park et al.，Facebook Reality Labs & UW，CVPR 2019）：latent code 条件化的连续 SDF 解码网络，7.4MB 表示整类形状（对比单张 512³ 位图 16.8MB）。latent 插值 = 形状变形，撤销/回退 = 回滚 latent 向量——状态被压成一个向量。
5. **OpenUSD**（Pixar，2012 开源；AOUSD 标准化中）：layer + opinion 栈，LIVRPS 强度排序，"最强 opinion 胜出"，弱 opinion 被遮蔽而非合并。撤销 = 移除 layer，stage 精确回到之前状态，不存在"部分成功的合并"。
6. **Parasolid rollback / ACIS history-and-roll**（Siemens / Spatial）：即便在最不可逆的 B-Rep 内核里，工业界也用"日志 + 回滚标记"做 undo——记录 mark 之间的增量，回退即重放状态，支持非线性分支历史。可见"结构可逆"的最低配实现是增量日志。

## 2. 已解决的问题（可直接抄）

- **撤销贵的根源是"编译到网格"这一步，不是表示本身。** CSG 树上撤销 = 剪掉子树 + 只重算受影响路径。我们架构里应把"AI 计划 → 修改器"改为"AI 计划 → 持久 CSG/参数树 + GN 作执行后端"，网格只是缓存。
- **SDF 布尔交换、可逆、局部**：union=min、diff=max(f,-g)。Blender 4.x GN 已内置 **SDF 栅格布尔节点**（官方手册 modeling/geometry_nodes/volume/operations/sdf_grid_boolean），我们应直接采用而非自己造轮子。
- **USD 模式映射**：每段 AI 计划写独立 layer（= 我们的 modifier=opinion），回退 = 丢弃 layer，零重算。PLM 实践结论（OpenUSD Core Spec 1.1 讨论）：下游可写层必须弱于已发布几何层，仅对未拥有数据（标注/状态）可强——值得写成我们的 layer 纪律。
- **增量求值**：OpenSCAD 改一参数全树重算（缓存粒度粗）；Antimony/Grasshopper 按 DAG 拓扑只传播下游。我们应为 GN 节点树做参数→子树的脏标记传播。

## 3. 坑 / 反直觉发现

- **SDF 有分辨率天花板**：窄带约 3 体素宽，锐利边角会被"圆角化/楼梯化"；分辨率从 128³ 到 512³ 内存与重网格化代价陡增（ChannelFlow-Tools 2025 实测对比）。窄带半宽是精度-内存旋钮，必须显式记录。
- **参数化 ≠ 全覆盖**：自由雕刻、扫描、修模类操作在 CSG/F-Rep 里只能靠变形场逼近（Antimony 的 attract/repel/bend 节点是唯一例外路径），OpenSCAD 完全无法表达。
- **神经隐式做不了精确布尔**：权重编码"不能轻易做形状组合"（多伦多大学 DeepSDF 笔记）；latent 插值不保拓扑，会产生意外孔洞/柄（SGI 2025 实测）。且压缩有损——违反我们"信息无损"判据。
- **USD 的 opinion 是有纪律的自由**：忘了移除的 overlay 会静默改变结果；opinion 只对当前 layer 栈权威。网格数据本身落层时，仍要面对网格表示的老问题——USD 只解决"编排可逆"，不解决"几何可逆"。
- **商业内核的回退也不免费**：Parasolid rollback 需注册 delta frustum、日志有内存代价，主要用于出错恢复而非撤销 UX。

## 4. 对本项目的建议

**(a) 该不该给布尔/切割引入 SDF 中间表示？** 该，且条件已成熟：Blender 原生 GN 已有 SDF 栅格布尔节点，SDF 段可以无缝留在"每段=一个 modifier"的体系里。触发条件：段落含布尔/切割/偏移/平滑类操作，且该段后续可能被参数微调或回退。窄带分辨率作为段落参数写入 GoodPoint；bake 成网格仍只发生在 GoodPoint 之后——这正好把 SDF 变成"参数层与网格层之间的无损中间态"。自由雕刻段落则跳过 SDF，直接走意图层。

**(b) CSG 树和 GN 节点树能统一吗？** 本质上是同构的：GN 的 Mesh Boolean/Join/Transform 对应 CSG 的 union/difference/transform，GN 节点树就是带几何内核的 CSG DAG 超集。统一方案：AI 编译目标从"网格 modifier"提升为"参数化 CSG 子树"，GN 是执行后端，树本身是可撤销的真源——这正是 Antimony 验证过的 DAG+F-Rep 架构。

- **神经隐式场**：不做核心表示（有损、布尔弱），但 latent 插值适合做"意图层重推"的候选生成器——在两个 GoodPoint 之间插值出中间形状供确认（未核实生产案例，属推断）。
- **回退三层的落位**：快照层管网格态；GoodPoint 层管 SDF/CSG 参数态（O(1) 回退主要发生在这里）；意图层管文本态。把"定位成本压零"用双向编程实现：3D 视图点选 → 反查树节点（arXiv 2408.01801 已在 OpenSCAD 上验证此交互）。
