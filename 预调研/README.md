## 各组一句话结论

**1 组｜参数化建模**：Synchronous Technology 的「局部重算 + 自动保持强约束」把改一个圆角从 60 秒压到 2 秒；Rhino 4 的**隐式历史**因为看不见而失败 → Grasshopper 的修正是**显式历史 DAG + 禁回环**；USD 的 **LIVRPS opinion 栈**天然就是三层回退。但 USD 对 Blender **不是**现成答案（官方手册明写导入导出都不支持 layers/references/variants，Blender Lab 的 Core USD Authoring 至今无资金无时间表）→ 语义抄 USD，存储自研。

**2 组｜撤销理论**：Cass & Fernandes NordiCHI 2006 用户实验证明人**自发偏好 cascading（依赖感知）undo**，直接给「推翻 Thought → 重推下游」背书；Blender issue #106903 实测 global undo = 把整个 `bmain` 序列化到内存，隐式共享后快 2–5 倍、内存 1.62GB→1.03GB（**"快照太贵"是错觉**）；Dolan PODC 2020 定理说可撤销的 CRDT 只有计数器 → **CRDT 这条路划掉**。

**3 组｜信任校准**：最反直觉的一条——Romeo & Conti 综述 35 项研究表明 **XAI 透明机制常常无效甚至反向**（过于技术性或过于简略的解释会加固错置信任），有效的是让用户**付出核验努力**。→ 思维图要做成**可一键反驳的按钮**，不是说明文字。另有同质化警告：Science Advances 2024 + Kobiella CHI'26。

**4 组｜AI 编程 Agent**：最成熟的对照系。硬数据：METR RCT 资深开发者**实测慢 19%**（事前预测快 24%）；Faros 2026 PR 评审时间 **+441%**、61.38% 的 agent PR 零评审；GitClear 2.11 亿行显示「重构行 24.1%→9.5%、重复块 8 倍」= **AI 只会加不会改**；Cognition（Devin 团队）放弃并行多 agent，链式成功率只有 20–40%。

**5 组｜图检索**：核心判断被验证——arXiv:2601.08773 的正面对决里，LLM 抽取的知识图在 Shopizer 上**漏掉 377 个文件**，而 AST 派生的图秒级建图且正确性最高。→ **骨架用 AST/RNA 确定性建，只有节点语义属性才用 LLM**。另两个硬坑：过滤检索在 1–20% 选择性是性能陷阱（必须先 oversample 再过滤）；Neo4j 内置向量召回 67.5% vs TigerVector 90.9% → **双库必要**。

**6 组｜认知科学**：Bilda, Gero & Purcell 2006 的**蒙眼实验**（专家建筑师不能草图时设计成果无显著下降）直接挑战了「外化越多越好」；Velloso CHI 2024（N=60）显示 ideation 阶段用 AI 会导致**更高 fixation、更少想法、更低多样性**。→ 外化判据要改成「× 专长 × 阶段」，且 ideation 期少外化。

## 交叉结论（多组指向同一处，优先级最高）

1. **定位粒度 = 物体 / 修改器节点级，不是顶点级、不是段落级**
   （4 组：APR 实证函数级 45.6% 最优且 σ 最低；5 组：HippoRAG 在需要两跳以上路径时才压过向量）

2. **Graph 依赖讲究确定性优先**
   （5 组：AST/RNA 建边；1 组：FlowAxis 改显式 DAG 禁回环；2 组：cascading undo = 显式依赖传播）

3. **验证器必须机械，不能让 LLM 自评**
   （4 组：verifier's law / Goodhart；5 组：噪声实体在图里被放大，比向量库更致命）

4. **过程 > 结果**
   （1 组：history-free 无用 vs 显式历史；2 组：事件日志是源头，向量/图只是它的物化视图）

5. **新人机上最难的一条：别让 AI 替你收窄想象力**
   （3 组 + 6 组独立指向同质化；解法是多样性闸门 + 早期少给后期多给）
