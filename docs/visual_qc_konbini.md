# 视觉核验失效复盘 + 动画感验收清单（2026-09-29）

## 一、失效三层（konbini v1/v2 案例）

1. **核验目标漂移**：8 轮预览全在做"构图检查"（在不在/挡不挡/亮不亮），
   用户要的"像不像日式动画"是美学判断——一次没做。确认偏误实锤。
2. **无参照系**：动画感的判断必须对照参考特征清单，凭印象说"有氛围了"不是核验。
3. **任务错位**：把"三渲二动画感"当渲染技术问题（toon+bloom+描边），
   实际是美术问题（色板纪律/光比/构图密度/材质分层）。technique ≠ look。

## 二、动画感验收清单 v1（对照 konbini_web.png 实测）

| # | 特征 | 参考（新海诚/吉卜力雨夜街角） | 实测 | 判定 |
|---|---|---|---|---|
| 1 | 色板纪律 | 全画面 ≤3 主色（深蓝紫夜 + 店内暖橙 + 一个霓虹点缀） | 输出 14+ 种材质色，灰/白/蓝/橙/粉混杂 | ✗ |
| 2 | 光比 | 店内：街道 ≈ 8:1（暗部压死，亮部留细节） | 全画面亮度均匀，无"暗部压死" | ✗ |
| 3 | 湿反光 | 锐利的高光条（灯的倒影拉长成竖条），非均匀泛光 | Wet 材质存在但无光源倒影条 | ✗ |
| 4 | 雨丝 | 可见的斜线雨（1-2px 亮线，有方向性） | 点状粒子，无方向性 | ✗ |
| 5 | 轮廓线 | 粗细随距离/明暗变化（近粗远细） | hull 等宽 1.035（无变化） | △ |
| 6 | 构图密度 | 前景遮挡物（雨伞/电线）+ 中景主体 + 远景空气透视 | 元素平铺无前后层次 | ✗ |
| 7 | 天空 | 深蓝渐变 + 云层被城市光照亮 | 纯色背景 | ✗ |
| 8 | 生活痕迹 | 招牌贴纸/电线缠结/积水的涟漪不规则 | 全部几何对称完美 | ✗ |

**结论：8 项中 0 项完全达标。** 这就是"一坨答辩"的定量解释——
不是某一项没做好，是**没有任何一项达到动画标准**。

## 三、修正后的核验纪律（对本项目所有视觉交付生效）

1. **先参考后动手**：视觉任务开工第一件事 = 列目标风格的特征清单
   （逐条可判"有/无"），不允许"凭感觉调"。
2. **每轮迭代 = 消灭最大差距项**：按清单排序，一次只攻最大差距，
   攻完重截重评——而不是随机调参。
3. **美学判定用"路人第一眼"**：假装第一次看到这张图，问
   "这像不像参考？"——不允许"确认我预期看到的东西"。
4. **几何上限诚实声明**：程序化 primitives 的美术上限是真实约束，
   达不到的特征（如手绘感笔触）明确标注"需手工美术/离线渲染"。

## 四、konbini 重做路线（按此清单逐项攻坚）

- 色板纪律（#1）：材质收敛 14→6（夜蓝紫底 / 暖橙光 / 品红招 / 青 vend /
  沥青黑 / 玻璃青）——其余一律归入这 6 色的明度变化
- 光比（#2）：环境光压到 0.3，店内暖光成为唯一亮源，街道只靠
  路灯/招牌点光 + 湿面高光条
- 湿反光（#3）：Wet 面用"竖条高光贴片"（每个光源倒影一根拉长亮条）
  ——动画夜雨的标志性笔触
- 雨丝（#4）：Points 改 LineSegments 斜线（-15° 方向，长 0.15）
- 构图（#6）：前景加一把撑开的伞（近景遮挡）+ 电线横过画面上部
- 天空（#7）：大背景球渐变（顶部深蓝紫 → 地平线被城市染亮的橙灰）
