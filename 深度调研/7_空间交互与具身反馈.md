# [d2-spatial] 空间交互 / 具身反馈 / 3D 编辑 UX 前沿

- 调研代理：d2-spatial ｜ 回报 2026-09-27 03:10
- 核心结论：优先级排序 = ① Grease Pencil 标注→分割→段落反查（零依赖）② 闪烁式 A/B diff（实证支持、极简）③ spearcons 语音 verifier 结果 ④ VR/触觉/手势远期

## 一、研究/交互模型（6 条，均已核实）
1. **Lasso 系 3D 选择**（TeddySelection/CloudLasso, TVCG 2012；Tangible Brush, CGF 2019）：2D 套索→视线挤出 3D 选区体积，密度自动定界。
2. **可提示分割（SAM 3, Meta 2025；SAMPart3D 2024/P3-SAM 2025）**：文本短语或单击点分割 mesh 语义部件。→ 与 AZURITE"区域→段落"反查天作之合。
3. **沉浸分析综述**（Fonnet & Prié, TVCG 2021）：VR 审查"多感官通道严重欠利用"。
4. **VR 比较任务**（CHI 2025）：VR 中并排不可行（一次一个 3D 空间）；时间位移式切换+局部区域控制胜出。
5. **视觉比较三分类**（Gleicher 经典）：juxtaposition/superposition/explicit encoding。
6. **简短音频警报元分析**（Nees & Liebman 2023）：spearcons > auditory icons > earcons（earcons 全面垫底）。

## 二、设计转译
1. 段落→可点选区域：渲染图上框选/套索 → SAM 分割面片组 → 反查 Thought 段落 → 对话注入"你选的是第 N 段"
2. A/B diff：对齐叠放+**闪烁**（Hild 2018：命中率 95%）优于并排；同机位同构图条件天然满足
3. 滑块擦拭模式：CHI 2026 沉浸视频比较（N=20）sliding 混合最受偏好（40%），适合逐区域精看
4. verifier→声音：不协和低音=严重度梯度；但**压缩语音（spearcons）比抽象蜂鸣有效**——"非流形边"播语音
5. 触觉（远期）：Scene2Hap（CHI 2026 最佳论文）LLM 生成振动反馈；桌面降级为鼠标悬停非流形区域短促振动
6. 手势映射：**风险高**——Quest 2 指尖误差 1.1cm、延迟 45ms，精细段落操作会频繁误触

## 三、反直觉
1. earcons 被元分析打脸（准确率/评分垫底）；语音提示反而最好
2. 手追踪精度不足以支撑精细编辑（1.1cm 误差 / 9.6° 关节角）
3. VR 审查非全面更优：VR 优势在具身深度理解，代价是设备/舒适度/学习成本
4. Blender 5.0 GreasePencil→Annotation API 重构——旧教程代码会失效

## 四、Blender 生态内可用（零新依赖）
1. **Grease Pencil/Annotation 标注即数据**：`bpy.ops.gpencil.annotate()` 产生结构化 stroke（坐标+压力），可读取反投影定位区域——"区域反查"最自然 UI
2. bmesh 选择状态全可编程：verts/edges/faces `.select` + `region_to_loop()` 可视化段落边界
3. 闪烁 diff 零插件：同机位渲两帧 + Compositor 叠加差异图
4. VR 可借内置 OpenXR addon，不自研
